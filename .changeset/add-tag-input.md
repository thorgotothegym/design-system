Add the `TagInput` component: a text field that turns what is typed into removable tags. Enter or a comma adds a tag, pasting a list adds several, Backspace in an empty input removes the last one, and each tag has a remove button reached with one tab stop and the arrow keys. Duplicates and a maximum are rejected with a polite announcement, and the empty list is not rendered. Controlled or uncontrolled, inside or outside a `Field`, and a native form submits one value per tag. Built on `@radix-ui/react-roving-focus`.
